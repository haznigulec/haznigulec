# Profile README visuals

The images in `assets/` and the root `README.md` are generated by `generate.mjs`. To change
the profile, edit the `PROFILE` object at the top of that file, then:

```sh
cd tools/readme-svg
npm install
npm run build     # writes ../../assets/*.svg and ../../README.md
npm run preview   # writes preview.html; open it in a browser to see the animations
```

Commit the regenerated files together with the change to `generate.mjs`.

Each SVG embeds its fonts (Space Grotesk, JetBrains Mono and Instrument Serif, all SIL Open
Font License), so the profile looks the same on every device. The motion is CSS and SMIL inside
the SVGs, which GitHub keeps playing in `<img>`.
